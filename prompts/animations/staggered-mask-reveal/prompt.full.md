# Staggered Mask Reveal — Extended

## Concept
Type is printed into place: masks feel like letterpress beds opening. Timing is musical — not random.

## Art direction
- Palette: darkroom `#1a1512`, walnut `#3b2f2a`, paper `#f0e6d8`, ink red accent `#b42318` (tiny)
- Type: Editorial New / Reckless / Fraunces for display
- Grain: 4% overlay

## Motion brief
1. Entrance: line 1 → 2 → 3 with 80–120ms stagger; ease out expo-ish
2. Ambient: none after settle
3. Interaction: optional replay button for demos only

## Timing tokens
- duration per line: 700–900ms
- stagger: 90ms
- distance: 110% of line height

## Constraints checklist
- [x] No blur mush
- [x] Reduced motion
- [x] Mobile: fewer lines / smaller amplitude
- [x] Avoid purple neon reveals

## Acceptance
Feels like a title sequence, not a ScrollMagic demo from 2016.

## Optional variants
- Variant A: vertical wipe
- Variant B: horizontal clip reveal
