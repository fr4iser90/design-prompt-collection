# Woven Reed Flex

Animate a close-up section of woven wicker/reed where strands flex under invisible tension.

**Visual Direction:**
- Show 5-7 vertical reed strands interlaced with horizontal strips.
- Simulate a "pull" effect: the vertical strands bend outward, then snap back slightly with damped oscillation.
- Highlight the friction points where strands cross.
- Use realistic lighting to show the cylindrical volume of each strand.

**Technical Constraints:**
- Use soft-body physics or IK (Inverse Kinematics) for the bending motion.
- Avoid rigid rotation; the bend must be continuous and smooth.
- Subtle shadow casting changes as strands move closer/further from the background.

**Deliverable:**
Three.js scene or high-fidelity CSS 3D transforms with SVG paths for the strands.
