# Porcelain Clasp Click

Create a micro-interaction animation featuring two interlocking porcelain components. 

1. **Visuals**: Two semi-circular porcelain lugs (matte white, subtle subsurface scattering) rotate on a fixed axis. 
2. **Motion**: They rotate slowly towards each other (0.5s ease-in), then snap into a flush position with a tiny, high-tension 'click' (scale bounce 1.0 -> 0.98 -> 1.0). 
3. **Sound**: A crisp, dry ceramic 'clink' plays on the snap.
4. **Background**: Clean, off-white (#f0f0f0) with a soft, diffused drop shadow to ground the object.
5. **Constraint**: No gears, no metal. Pure ceramic-on-ceramic interaction. Loop indefinitely.
