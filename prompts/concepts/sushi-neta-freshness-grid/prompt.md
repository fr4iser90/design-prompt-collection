# Sushi Neta Freshness Grid

Design a precision dashboard for a high-end sushi counter. 

**Visuals:**
- Grid of 'Neta' (toppings) tiles. Each tile shows a minimalist icon of the fish, a freshness score (0-100), and a micro-timeline.
- Background: Cool white (#F0F4F8) with faint blue grid lines.
- Tiles: White cards with subtle drop shadows. 
- Data Viz: A thin horizontal bar under each tile showing 'Time Since Catch'. Color shifts from Blue (Fresh) to Red (Degraded) as time passes.
- Typography: Swiss style. Sans-serif, small caps for labels. Numbers are large and monospaced.

**Motion:**
- Load: Tiles fade in sequentially.
- Interaction: Hovering a tile expands it to show a detailed graph of temperature history.
- Ambient: The freshness bars slowly shrink over time (simulated live data).
