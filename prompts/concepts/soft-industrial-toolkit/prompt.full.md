# Soft Industrial Toolkit — Extended

## Concept
Appliances as calm tools. Interfaces borrow gasket lines, stamped type, and porcelain fills — never cartoon knobs.

## Art direction
- Palette: machine gray `#1c1f24`, aluminum `#d9dde3`, porcelain `#f7f4ef`, copper signal `#c27a4a`, gasket `#5c6570`
- Type: Diligent / Söhne-class grotesque + JetBrains Mono for specs
- Radius: 12–20px on controls; 0 on structural rules
- Stroke: 1.5px aluminum lines; warning stripe motif only in utility states

## Sample compositions
1. Product hero: full-bleed object photo, brand oversized, one line, one CTA
2. Spec strip: mono labels, no card chrome — just rules and columns
3. Packaging story: material close-ups as full-bleed planes

## Motion principles
1. Soft settle on load (opacity + 6px)
2. Control press with 1px travel
3. Copper accent line grows on focus

## Constraints checklist
- [x] Soft ≠ cutesy
- [x] Industrial ≠ steampunk
- [x] Brand first in samples
- [x] Tokens documented

## Acceptance
A landing built from this toolkit feels like a physical object catalog, not a SaaS trial page.
