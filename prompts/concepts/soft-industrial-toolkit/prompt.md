# Soft Industrial Toolkit

Create a **design toolkit / concept system** for **Hearthware**, appliances that feel like soft industrial objects.

## Intent
- Guide product landing pages + packaging-adjacent web moments
- Mood: brushed aluminum + warm porcelain — humane machines

## Hard rules
- Define material language (metal, ceramic, rubber gasket cues) as UI metaphors without skeuomorphic junk.
- Token set: color, type, space, radius, stroke, motion.
- Radii are soft but shapes stay machine-true (no playful blobs).
- Brand name "Hearthware" must outrank marketing headlines in sample compositions.
- Provide do/don’t for photography and for motion (2–3 motions max).
- Explicitly reject purple SaaS gloss and rustic farmhouse aesthetics.

## Deliver
Compressed operating brief in `prompt.md`; full token + sample compositions in `prompt.full.md`.
