# Nocturnal Garden Moodboard

Produce a **brand moodboard concept** (art direction, not a multipage site) for **Lumenflora**, a nocturnal botanicals house.

## Intent
- Lock atmosphere before any UI build
- Mood: velvet night, wet leaves, bioluminescent tips — romantic but sharp

## Hard rules
- Describe 6–9 locked references: color chips, type specimens, photo directives, texture, forbidden looks.
- Brand "Lumenflora" appears as a typographic specimen at hero scale in the written composition.
- Prefer real botanical night photography direction over abstract neon gradients.
- Motion language for future pages: dew shimmer, slow petal drift (2–3 only).
- Reject purple cyber-garden and cute cottagecore.

## Deliver
Operating brief + extended moodboard doc that a build agent can turn into a one-page visual HTML board later.
