06

Motion language — three, no more

Storyboard frames for future pages. Everything slow, biological, restrained.

M·01

Dew shimmer

Opacity delta 0.35 → 1.0 over 2.8s. Staggered, never in sync. Only on water beads and lumen points.

M·02

Slow petal drift

Vertical descent, 9s loop. Background botanicals only, 6–10% opacity. Reads as settling, not falling.

M·03 engraved

Type ink-in

Words reveal left-to-right like ink soaking into leaf-dark. 3s on enter, once per heading. No bounce.

Operating brief

Six rules a build agent can execute against. Atmosphere over chrome.

Build the atmosphere first. If a screen can be mistaken for a crypto garden, a cottage, or a fairy-lit café — it is wrong. Light is grown, never plugged in.
