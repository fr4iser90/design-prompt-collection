# Anodized Titanium Blotter

**Concept:** A UI for selecting brand colors via titanium anodization. The user adjusts a 'Voltage' slider, causing a central metal plate to shift its oxide layer color.

**Visual Rules:**
- **Subject:** A rectangular titanium plate with a brushed grain texture. 
- **Interaction:** Dragging the slider changes the color shift (Straw -> Gold -> Blue -> Purple -> Green). 
- **Lighting:** The color should not look like a flat fill. It must simulate thin-film interference. Moving the mouse over the plate should shift the hue slightly (iridescence).
- **UI:** Minimal controls. A single slider and hex code readout. No buttons other than 'Copy'.
- **Atmosphere:** Clean, laboratory-like. White background, soft shadows.

**Deliverable:** A React component with a CSS-filter/gradient hack or Canvas simulation for the iridescent effect.
