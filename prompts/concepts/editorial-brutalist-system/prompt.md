# Editorial Brutalist System

Define a complete **art-direction system** (not a full website build) for a magazine-tech hybrid brand called **BLOCK**.

## Intent
- Deliver a system brief another designer/AI can execute consistently
- Mood: concrete, ink, voltage — brutalist but editorial, not meme-brutalism

## Hard rules
- Specify: palette tokens, type pairing, grid (columns/margins), rule weights, photo treatment, motion principles, do/don’t.
- Brand "BLOCK" must be treated as a typographic monument in examples.
- Avoid hairline broadsheet pastiche AND soft cream+terracotta luxury defaults.
- Include 3 component recipes (nav, article header, image+caption) described in words + ASCII/wire proportions — not card UI kits.
- Motion: only structural (rule draw, ink settle) — max 3 principles.

## Deliver
A single `prompt.full.md`-quality system doc is the product; `prompt.md` is the compressed operating brief to paste into a build agent.
