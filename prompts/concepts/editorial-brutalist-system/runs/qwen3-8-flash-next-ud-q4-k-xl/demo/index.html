01 MANIFESTO

BLOCK is printed concrete. The grid is load-bearing. Ink is the voice. Orange is electricity — a weld, not a paint job.

This document is not a website. It is an operating system for a page: tokens, weights, rules and motion that any designer or build agent can execute into the same family of results. Siblings, not cousins. Concrete, ink, voltage.

01
Concrete
Surfaces feel poured, not printed. Structure is honest; nothing pretends to float.
02
Ink
Type carries the argument. Hierarchy is set by weight and scale, never by decoration.
03
Voltage
Weld orange is a joint, not a gradient. Sparing. A single charged point per field.
04
Load
Every rule holds weight. The 2px line is structural — it never becomes a hairline ornament.

05 RULE WEIGHTS

2PX,
ALWAYS.

The structural rule is 2px and black. It separates, divides and carries weight. The 1px "newspaper" hairline is forbidden as an aesthetic — it is delicate where the system must be load-bearing.

2PX
Structural
The default. Divides sections, frames components, underlines the masthead. Black on paper, paper on asphalt.
4PX
Emphasis
Reserved for a single charged moment — a hover state, an active joint. Used once per view at most.
1PX
Forbidden as aesthetic
Hairline broadsheet pastiche is off-limits. A 1px line may exist only as an internal grid guide — never as a visible design element. The rule is concrete or it is not there.

06 PHOTO TREATMENT

CRUSHED
BLOCKS.

Photography is concrete too: high contrast, crushed blacks, desaturated. A weld duotone overlay may sit at ≤15% — a charge, never a wash. No soft gradients, no pastel filters.

FIG.01 // CRUSHED BLACKS
01
Desaturate
Grayscale by default. Colour is the weld's job, not the photo's.
02
Crush
Push contrast so blacks go solid. The image should feel poured, not printed.
03
Duotone weld
Occasional #ff3b00 soft-light overlay at ≤15%. One charge per image, never more.
04
Frame
A 2px structural border, flush. No drop shadows, no rounded corners, no bloom.

08 MOTION PRINCIPLES
