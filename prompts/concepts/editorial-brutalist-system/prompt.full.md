# Editorial Brutalist System — Extended

## Concept
BLOCK is printed concrete. The grid is load-bearing. Orange is electricity, used like a sparingly welded joint.

## Art direction
- Palette: asphalt `#111111`, paper `#f4f4f0`, weld `#ff3b00`, mid gray `#8a8a84`
- Type: Monument Grotesk / Neue Haas Grotesk Display + IBM Plex Mono for meta
- Grid: 12-col desktop, 4-col mobile; margins 4–6vw; gutters tight
- Rules: 2px black structural rules; never 1px delicate “newspaper” hairlines as the aesthetic
- Photo: high contrast, crushed blacks, occasional duotone weld overlay at ≤15%

## Layout recipes
1. Nav: brand left huge; links as mono list right; bottom rule
2. Article header: mega title spanning 8 cols; deck in 4 cols; no hero card
3. Image+caption: full-bleed image; caption in mono under a 2px rule

## Motion principles
1. Rules draw on enter
2. Titles settle from 4px offset
3. Hover = rule thicken, not shadow bloom

## Constraints checklist
- [x] System > page
- [x] No soft-luxury cliché
- [x] No purple tech glow
- [x] Brand as monument

## Acceptance
Three different AIs building from this doc should produce sibling pages, not cousins.
