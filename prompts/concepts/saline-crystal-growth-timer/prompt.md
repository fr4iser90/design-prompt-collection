# Saline Crystal Growth Timer

Create a countdown timer interface visualized through crystallization.

**Visual Rules:**
1. **Mechanism:** A central pool of liquid (pale indigo `#e0e7ff`). Over time, white/blue crystalline structures (`#6366f1` to `#1e1b4b`) grow from the edges inward, narrowing the liquid area.
2. **Aesthetics:** Sharp, faceted geometry. No organic blobs. Crystals should look like precise mineral formations (halite).
3. **State:** 
   - Start: Open liquid surface.
   - End: Fully solidified/crystallized block.
4. **Interaction:** User can 'agitate' the liquid (click/drag) to slow crystal growth (entropy), or let it sit to speed up growth (order).

**Deliverable:** A canvas-based or WebGL implementation of the crystal growth animation with UI overlay.
