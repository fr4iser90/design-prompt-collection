# Kiln-Fired Glaze Sample

Create a UI concept for selecting ceramic glazes. The interface should feel like a potter's shelf.

**Core Metaphor:**
- Users select colors by picking up physical glaze tiles.
- Tiles are not flat squares; they are irregular, hand-thrown discs with visible brush strokes and drip edges.
- Lighting simulates kiln glow: warm, directional, casting long shadows from the tiles.

**Interaction:**
- Hovering a tile lifts it slightly (z-axis transform) with a subtle "clink" sound implication (visual vibration).
- Clicking selects the tile, causing a ripple effect as if the glaze is still wet.
- Transitions between selected colors involve a heat-shimmer distortion effect.

**Visual Style:**
- Background: Dark, matte clay texture (#2a1b14).
- Typography: Serif, elegant, low-contrast, like kiln labels (#e9edc9).
- No UI chrome (buttons, borders). Objects are the interface.
