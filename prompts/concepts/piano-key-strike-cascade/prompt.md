# Piano Key Strike Cascade

**Concept**: Typography as a keyboard instrument. Each letter is a flat, rectangular key. Text appears by 'striking' each key down in a sequence, accompanied by a subtle visual recoil.

**Visual Rules**:
1.  **Base State**: Letters are flat, white rectangles on a dark background. Text is hidden or ghosted.
2.  **Strike Motion**: When a letter is activated, it moves down (translateY) and rotates slightly (rotateX) as if a hammer hit it.
3.  **Recoil**: The letter bounces back up with a spring physics dampening.
4.  **Sequence**: Text reveals left-to-right or in a custom rhythm. The 'strike' creates a visual pulse.
5.  **Accent**: A gold line or glow appears on the bottom of the key during the strike, fading quickly.

**Deliverable**: HTML/CSS/JS demo. Use CSS `perspective` and `rotateX` for the 3D key effect. JS for sequencing the strikes.
