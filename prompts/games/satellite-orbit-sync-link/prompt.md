Deliverable: single-file HTML/CSS/JS. Build 'Satellite Orbit Sync', a rhythm-timing game in Canvas 2D. The player manages a ground station receiving data from 3-5 satellites orbiting at different radii and speeds. Core mechanic: Click to drop a data packet from the currently highlighted satellite. The packet falls straight down (or towards center) due to simulated gravity/inertia. A 'Receiver Window' (a glowing arc segment at the bottom or center) opens and closes rhythmically. The packet must land inside the window while it is open to score. If it lands while closed, or misses the window entirely, it is a miss. 5 misses end the run. Goal: Transfer 100GB (100 successful packets). Visuals: Deep space background (#050510). Satellites are white geometric shapes (#FFFFFF) with blue trails (#0088FF). The receiver is a pulsing blue arc. HUD uses Futura for scores and Courier New for telemetry data. Input: Single click/tap. The game must be playable end-to-end. No landing page elements. Ensure the timing is fair but requires anticipation of orbital position vs. window phase. Layout must be responsive: on desktop, the canvas centers with a fixed aspect ratio; on mobile, it fills the viewport height, scaling entities proportionally. Motions should be smooth, using requestAnimationFrame. Constraints: No external assets. Acceptance criteria include smooth 60fps performance, accurate collision detection, and clear visual feedback for hits and misses. Implement a state machine for Start, Playing, GameOver, and Win states. Add subtle screen shake on miss and particle bursts on success. Ensure touch targets are large enough for mobile play. Use delta-time for consistent physics across different frame rates. The receiver window should have a visual cue for its opening/closing phase, such as a shrinking ring or color gradient shift, to aid player timing. Include a combo counter that resets on miss. The background should feature a static starfield with slight parallax if possible, or just static stars to save performance. Ensure the code is modular and commented for readability.
