# Boulangerie Crumb Structure

Create a landing page for 'Levain & Air', an artisanal sourdough bakery.

**Visual Direction:**
- **Palette:** Warm beige (#F5F5DC), toasted crust (#D2B48C), deep rye (#8B4513).
- **Layout:** Asymmetric grid that mimics the irregular holes in bread crumb. Use whitespace as "air pockets."
- **Typography:** Serif display font (e.g., Playfair Display) for headings, clean sans-serif for body. High contrast.
- **Imagery:** Macro shots of bread interiors, not whole loaves. Focus on texture and translucency.

**Motion:**
- **Entrance:** Text fades in with a slight "rise" animation (translateY up + scale up).
- **Ambient:** Background images slowly pan horizontally, simulating the camera moving along a sliced loaf.
- **Interaction:** Hovering over text reveals a subtle grain texture overlay.

**Deliverable:**
- Responsive landing page (desktop/mobile).
- No hero cards; use full-bleed imagery with overlay text.
- One clear CTA: "Order Today's Bake".
