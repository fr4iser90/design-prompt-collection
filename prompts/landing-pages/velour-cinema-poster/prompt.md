# Velour Cinema Poster

Create a landing page for the film 'Velour'. Aesthetic: Film Noir. Background is deep charcoal (#0f0f0f). The title 'VELOUR' is in a serif font, gold (#d4af37), with a long, hard shadow that moves as the cursor moves (parallax). Light beams (CSS gradients) cut across the screen diagonally. The layout is poster-like: Title, Date, 'Book Now'. Motion: The shadow should be 'slung' behind the text, reacting to mouse velocity. Atmosphere: Mysterious, elegant, high-contrast.
