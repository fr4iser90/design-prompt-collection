# Microfiche Scan Archive

Create a landing page for "MicroSearch," a service that digitizes and indexes physical archives.

**Visual Rules:**
- **Theme:** High-contrast Black & White. No color, except for a single accent (e.g., amber or green) for interactive states.
- **Background:** Dark (#000000) with a subtle, moving scanline effect or CRT curvature overlay.
- **Typography:** Bold, blocky sans-serif (e.g., Archivo Black) for headlines, mimicking library signage. Monospace for search inputs.
- **Hero:** A large, glowing search bar that looks like a microfiche reader screen. Text inside the search bar types itself out as if being scanned.
- **Imagery:** Abstract representations of text pages, blurred and focused, like a camera lens finding focus.

**Deliverable:** A hero section with an interactive search bar and a "results" preview that mimics a microfiche card.
