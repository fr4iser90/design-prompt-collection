# Tidal Studio Hero — Extended

## Concept
A dawn coastal plane fills the viewport. "Tidal" sits large in the optical center-left; a short headline rides below like a caption, not a billboard. Water is the brand — not decoration behind a card.

## Art direction
- Palette: deep tide `#0b1c24`, kelp `#163a45`, foam `#e8f1ef`, signal mint `#7ec8c3`, sand highlight `#d4c4a8`
- Type: Fraunces or Newsreader (display) + a narrow mono for micro-labels
- Imagery: real coastal atmosphere (horizon, soft fog, wet sand) — not abstract blobs
- Texture: 3–5% film grain; subtle vignette toward corners

## Layout
### Desktop
- Brand top-left / optical hero; headline under brand; CTA row under sentence; visual plane full-bleed behind everything with readable scrim only where type sits
### Mobile
- Same hierarchy stacked; reduce display size; keep full-bleed; CTA sticky-friendly but not a junk bar

## Motion brief
1. Entrance: type resolves from soft blur → crisp over ~700ms staggered
2. Ambient: horizon / grain drifts extremely slowly
3. Interaction: CTA secondary link gets a tide-line underline grow

## Constraints checklist
- [x] Brand first
- [x] One headline + one sentence + one CTA group
- [x] Full-bleed hero visual
- [x] Avoid purple SaaS / cream terracotta / broadsheet clichés
- [x] Reduced-motion fallback

## Acceptance
Remove the nav: still unmistakably Tidal. Feels art-directed, not ThemeForest.

## Optional variants
- Variant A: photographic dawn
- Variant B: painterly ink-wash sea with the same type system
