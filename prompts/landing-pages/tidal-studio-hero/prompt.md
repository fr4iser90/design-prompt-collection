# Tidal Studio Hero

Design a single-viewport landing hero for **Tidal**, a coastal brand studio. The brand name must dominate; the headline must not overpower it.

## Intent
- Primary goal: book a discovery call
- Audience: founders who want art-directed sites, not templates
- Mood: saline, precise, quiet luxury — dawn over cold water

## Hard rules
- One composition (not a dashboard). Brand "Tidal" is the hero-level signal.
- Expressive type: display in a high-contrast serif or grotesque with character (e.g. Fraunces / Newsreader + Geist Mono for labels). No Inter/Roboto/Arial/system.
- Background is a full-bleed ocean/atmosphere plane (photo or painterly gradient + grain), edge-to-edge — not an inset image card.
- First viewport only: brand, one headline, one short sentence, one CTA group, dominant visual. No stats, schedules, address blocks, or promo chips.
- No cards, no floating badges on the media.
- Motions (2–3): (1) slow horizon drift / tide line, (2) type fade-up with slight blur resolve, (3) CTA underlines that swell on hover. Honor `prefers-reduced-motion`.

## Deliver
Production-ready HTML/CSS (+ minimal JS for motion). CSS variables for palette. Desktop + mobile.
