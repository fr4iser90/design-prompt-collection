# Fermentation Clock Timer

**Concept:** A landing page for a home fermentation kit brand. The core visual metaphor is time. The hero features a real-time, interactive 'clock' where bubbles rise from the bottom, representing the fermentation process. The speed of bubbles correlates with the temperature and stage of fermentation.

**Visual Rules:**
- **Palette:** Dark background (`#1A1A1A`), amber/gold for bubbles (`#FFBF00`), and white text.
- **Texture:** Glass-like transparency for the 'jar' container. Subtle condensation effects.
- **Typography:** Monospace font for the 'timer' and data points. Clean sans-serif for marketing copy.
- **Layout:** Centralized 'jar' element. Marketing copy surrounds it. The jar is the hero.
- **Motion:** Continuous, slow-rising bubbles. The bubbles should have physics (slight wobble, varying speeds).

**Deliverable:** A single-page HTML/CSS/JS implementation featuring a canvas-based or CSS-based bubble animation that simulates fermentation, with a digital timer overlay.
