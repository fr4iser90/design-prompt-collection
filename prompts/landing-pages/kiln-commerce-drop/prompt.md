# Kiln Commerce Drop

Build a product-drop landing page for **Kiln**, a small-batch ceramics brand launching a single vessel.

## Intent
- Primary goal: sell the drop (limited units)
- Audience: design-literate shoppers who care about material honesty
- Mood: kiln heat, matte clay, quiet confidence — warm but not “farmhouse”

## Hard rules
- Brand "Kiln" is the strongest type signal in the first viewport.
- Full-bleed product photograph or 3D render as the visual plane (edge-to-edge). No inset rounded product card in the hero.
- First viewport: brand, one headline, one supporting sentence, one CTA group (Buy / Notify). No promo stickers, sale badges, or floating chips on the image.
- Typography: characterful display (e.g. Literata / Fraunces) + clean grotesque body. Ban Inter/Roboto/Arial/system as the prescribed stack.
- Background atmosphere from the clay/heat of the image (graded dark edges), not flat fill.
- Motions: (1) soft product light breathe, (2) headline letterspacing settle, (3) CTA press/scale micro-interaction. Respect reduced motion.

## Deliver
HTML/CSS (+ light JS). CSS variables. Desktop + mobile. Optional second section for craft story — but hero stays one job.
