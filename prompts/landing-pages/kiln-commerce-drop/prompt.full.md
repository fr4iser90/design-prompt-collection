# Kiln Commerce Drop — Extended

## Concept
The vessel owns the frame. Type is typeset like a gallery label that grew into a brand mark. Heat is implied through color grade and a slow light pulse — never through emoji fire or sticker overlays.

## Art direction
- Palette: kiln black `#2a1a14`, umber `#5c3317`, bisque `#e7d5c0`, ember `#e09f5a`, ash `#8a7a6c`
- Type: Literata or Fraunces (display) + Satoshi/General Sans–class grotesque for UI
- Imagery: single hero object, tactile glaze, shallow DOF
- Texture: soft chalk noise; avoid heavy paper mock “print” frames

## Layout
### Desktop
- Product full-bleed right-weighted or centered; type left or lower-left with scrim only under glyphs
### Mobile
- Product still full-bleed; type stacked over lower third; CTA full-width but not card-wrapped

## Motion brief
1. Entrance: image grade lifts from underexposed → correct exposure
2. Ambient: specular highlight drifts slowly across glaze
3. Interaction: Buy button compresses 1–2px on press

## Constraints checklist
- [x] Brand first
- [x] Hero budget respected
- [x] No cards in hero / no badges on media
- [x] Avoid cream+terracotta template look even though warm — push darker kiln blacks
- [x] A11y contrast on CTAs

## Acceptance
Looks like a limited drop microsite, not a Shopify default theme.

## Optional variants
- Variant A: matte black clay
- Variant B: speckled stoneware on charcoal
