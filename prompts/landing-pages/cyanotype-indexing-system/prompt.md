# Cyanotype Indexing System

Design a landing page for 'Prussix', a data verification protocol. The aesthetic is strictly large-format cyanotype: deep Prussian blue background (#003153) with white (#e6f2ff) typographic elements that appear 'printed' by light.

**Core Mechanics:**
1. **UV Cursor Reveal**: The cursor acts as a UV light source. As it moves over specific 'redacted' or 'latent' data blocks (slightly darker blue), they bleach to white, revealing the text underneath (simulating the chemical reduction of iron salts).
2. **Static Grid**: Layout is a strict 12-column grid with thin, light-blue hairlines resembling contact-printing tape.
3. **Typography**: Use a monospaced serif hybrid (e.g., 'Space Mono' or 'IBM Plex Mono') for data labels, and a clean, humanist sans (e.g., 'Work Sans') for headings. All text must look slightly embossed or debossed into the paper texture.

**Visual Rules:**
- No gradients. All color shifts are hard-edged or soft-focus bleeds.
- Background must have a subtle paper grain texture (noise) visible in the blue areas.
- 'Verified' statuses appear as small, white 'stamp' marks with a slight rotation.

**Deliverable:**
HTML/CSS/JS implementing the UV-cursor bleach effect on 3 distinct data blocks, with a hero section explaining the 'light-based verification' concept.
