# Firefly Swarm Choreography

Create a landing page for 'Lumina Nights', a high-end outdoor event curator.

**Visual Core:**
- **Background:** Deep twilight blue/black gradient (#0f172a to #1e293b). Subtle silhouette of trees at the bottom.
- **Hero Element:** A swarm of 100-200 'fireflies' (glowing yellow-green particles). They move in a loose, organic flock.
- **Interaction:** The user's cursor acts as a 'light source' or 'wind' that gently guides the swarm. When the cursor holds steady, the fireflies cluster around it, forming a glowing shape or revealing hidden text behind the swarm density.
- **Typography:** Elegant, thin serif font. White. Appears only when the swarm disperses or on click.

**Constraints:**
- Fireflies must not look like static dots. They need a 'glow' effect (box-shadow or blur).
- Movement must be smooth and fluid, not jittery.
- No bright daytime colors. Keep it 'night-time'.

**Deliverable:**
- HTML/CSS/JS with Canvas API for particle system.
