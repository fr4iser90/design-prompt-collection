# Northline Fintech Clarity

Design the first viewport for **Northline**, a B2B fintech that sells cash-flow clarity (not “AI magic”).

## Intent
- Primary goal: start free trial
- Audience: CFOs / operators tired of noisy dashboards in marketing
- Mood: north light, paper precision, calm authority

## Hard rules
- Brand "Northline" is hero-level; headline is secondary.
- One composition — do **not** dump charts, KPI strips, or mini-dashboards into the first viewport.
- Atmospheric background: cool daylight gradient + subtle paper grain or soft architectural photo plane, full-bleed. Not flat white.
- Expressive but sober type (e.g. Instrument Serif or Reckless + IBM Plex Sans). No Inter/Roboto/Arial as the design’s personality.
- First viewport: brand, one headline, one sentence, one CTA group, one dominant visual idea (e.g. abstract ledger light / horizon line — not a UI screenshot collage).
- No cards in the hero. No floating “SOC2” stickers on the media (trust can live in a later section).
- Motions: (1) horizon line draws, (2) type fades with crisp settle, (3) CTA focus ring breathes once. Reduced-motion safe.

## Deliver
HTML/CSS (+ minimal JS). CSS variables. Desktop + mobile.
