# Northline Fintech Clarity — Extended

## Concept
Marketing that refuses dashboard cosplay. Clarity is communicated through light, spacing, and a single abstract visual metaphor (ledger line / northern horizon), not through fake product chrome in the hero.

## Art direction
- Palette: ink `#0f1720`, slate blue `#1e3a4c`, paper `#f3f1ea` (use sparingly as type/CTA, not whole-page cream cliché), signal `#3d8bfd`, fog `#c5d0da`
- Type: Instrument Serif / Reckless Neue (display) + IBM Plex Sans (body/UI)
- Imagery: architectural north light, glass, soft shadow — or a crafted abstract ledger graphic
- Avoid: purple gradients, neon glows, rounded-full pill spam

## Layout
### Desktop
- Brand and copy left; visual plane full-bleed with controlled contrast under type
### Mobile
- Stack copy; keep visual atmospheric; never shrink into a floating media card

## Motion brief
1. Entrance: thin horizontal rule draws left→right
2. Ambient: almost imperceptible light shift
3. Interaction: primary CTA focus/hover uses exact brand blue, no glow bloom

## Constraints checklist
- [x] Brand first
- [x] No hero cards / no sticker overlays
- [x] No purple-SaaS default
- [x] Trust badges only below fold
- [x] Reduced motion

## Acceptance
Reads as finance-grade calm. Could not be mistaken for a generic AI wrapper landing.

## Optional variants
- Variant A: light north paper
- Variant B: dusk ink with the same restraint
