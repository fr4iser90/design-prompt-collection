# Glyph Foundry Typespecimen

Design a landing page for 'Glyph', a digital type foundry. The entire page is a live specimen. The hero text 'GLYPH' is editable by the user. Include sliders for Weight, Width, and Opacity. The background is pure white. Type is pure black. Active controls are #ff5722. The layout is a brutalist grid where the type *is* the structure. No images, only type. Motion should be crisp and mechanical, like a typewriter or a printer.
