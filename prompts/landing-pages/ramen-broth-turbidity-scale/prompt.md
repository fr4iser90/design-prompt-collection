# Ramen Broth Turbidity Scale

**Concept:** A culinary landing page for a high-end instant ramen brand where the visual language mimics the physical state of broth—specifically its turbidity and heat.

**Visual Rules:**
- **Palette:** Bone white background, creamy beige (broth), deep brown (tare), and charcoal (nori/chashu accents).
- **Texture:** Use SVG filters or CSS blend modes to create a 'milky' opacity overlay that intensifies as the user scrolls, simulating the reduction of broth.
- **Typography:** Clean, sans-serif for UI elements; elegant serif for flavor notes. No playful fonts.
- **Layout:** Vertical progression from clear (water) to opaque (broth). The hero is a macro shot of chopsticks lifting noodles, with steam rising into the text layer.
- **Motion:** Slow, viscous movement. Elements don't snap; they float and settle like fat droplets in hot soup.

**Deliverable:** A single-page HTML/CSS/JS implementation focusing on scroll-driven opacity transitions and a 'steam' particle effect that rises from the bottom center.
