# Index Card Sort System

Create a landing page for "SortWell," a tool for organizing research notes and citations.

**Visual Rules:**
- **Background:** Off-white paper color (#f5f5f0) with a very subtle paper grain texture.
- **Layout:** Elements look like physical 3x5 index cards, slightly overlapping or stacked. Use subtle shadows to indicate depth/stacking.
- **Typography:** Headlines in a clean sans-serif (e.g., Helvetica Now). Body text in a readable serif. Key terms have "hand-drawn" style underlines (SVG paths).
- **Color Accents:** Red (#d32f2f) and Blue (#1976d2) ink colors for highlights, mimicking colored pens.
- **Motion:** Cards shuffle or slide on hover, like someone flipping through a stack. Entrance is a "stack" dropping into place.

**Deliverable:** A hero section with a stack of cards representing "notes" and a feature section showing cards sorting themselves.
