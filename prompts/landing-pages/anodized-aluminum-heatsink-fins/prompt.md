# Thermal Flow: Aluminum Heatsink Hero

Create a landing page for 'Thermal Flow' audio amplifiers. The hero section features a full-width, high-resolution macro image of brushed aluminum heatsink fins. 

**Visual Rules:**
- **Material:** Matte anodized aluminum. No glossy chrome. Use subtle specular highlights to show curvature.
- **Motion:** On hover, individual fins gently oscillate (rotate Y-axis slightly) as if disturbed by a breeze. This creates a ripple effect across the fins.
- **Color Palette:** Industrial greys (#4a4a4a, #c0c0c0), white background, and a single accent color for active states (#ff6b00, representing heat).
- **Typography:** Clean, technical sans-serif (e.g., Helvetica Neue or similar, but not Arial). Heavy weight for 'Thermal Flow', light weight for specs.
- **Layout:** Hero image takes 60% of viewport height. Product specs float over the fins in a translucent, frosted-glass card (blur 10px).

**Deliverable:** A single HTML file with embedded CSS/JS for the hover interaction.
