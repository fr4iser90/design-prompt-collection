# Ledger Rule Alignment

Design a landing page for 'Balanced Books', a modern accounting SaaS. The aesthetic is a digital replica of a physical accounting ledger: ruled lines, column headers, and precise alignment.

**Core Mechanics:**
1. **Visible Grid**: The background features faint, horizontal blue rules and vertical column dividers, like a legal pad.
2. **Snap-to-Rule**: Headings and key metrics are strictly aligned to these rules. No floating elements.
3. **Debit/Credit Visuals**: Use color coding: Blue for 'Credits/Assets', Red for 'Debits/Liabilities' (used sparingly for contrast).

**Visual Rules:**
- Typography: A clean, tall serif (e.g., 'Lora') for numbers, and a strict sans (e.g., 'Inter') for labels.
- Borders: All containers have a 1px solid border in `#003366`.
- Paper Texture: Very subtle off-white background (`#f0f0f0`) with a faint watermark of the company logo.

**Deliverable:**
HTML/CSS layout with 3 columns (Date, Description, Amount). Implement a 'hover' effect that highlights the entire row (like a physical row highlighter) and a 'total' row that sums up the visible numbers dynamically.
