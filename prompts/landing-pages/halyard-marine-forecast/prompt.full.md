# Halyard Marine Forecast — Extended

Concept: Halyard is a weather-intelligence platform for commercial shipping and offshore teams. The landing page should feel like a navigational instrument: precise, cold, and quietly expensive. Lead with the brand name at hero scale, then a route ribbon crossing the viewport like a charted path. Keep the page information-dense but calm, with thin rules, coordinate labels, and a clear conversion band.

Palette: #071118 for the primary background, #162a3a for secondary chart depth, #ff7a18 for signal accents, route highlights, and primary actions.

Type pairing: Neue Haas Grotesk Display for brand and section headings, Tiempos for body and supporting copy, Söhne Mono for coordinates, telemetry, and metadata.

Layout desktop: use a 12-column asymmetric grid with a full-bleed hero, a split forecast table, a route case study, and a dense footer. The hero keeps the brand and one CTA dominant, with telemetry anchored to the right.

Layout mobile: stack into a single column with sticky compact nav, condensed route summary, tap-friendly CTA band, and a condensed forecast list.

Motion brief: entrance: route ribbon draws across the hero and headline letters rise slightly; ambient: coordinate ticks fade and a data ticker loops slowly; interaction: hover on route points reveals a small label and a map pin pulse.

Constraints: no purple glow, no generic SaaS hero cards, no stock ocean photography, no more than 3 motion types, and all text legible on dark backgrounds.

Acceptance criteria: brand reads first, palette feels marine and technical, motion supports reading, responsive layout is clean, and the page ships as one self-contained landing page.

Variants: A uses a horizontal route ribbon. B uses a radial compass motif with the same palette and type.
