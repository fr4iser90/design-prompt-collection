# Sous-Vide Precision Lab

Build a landing page for 'Vapor & Steel', a high-end sous-vide circulator brand. 

**Visual Direction:**
- **Atmosphere:** Sterile, precise, cold. Think laboratory meets professional kitchen.
- **Palette:** Deep slate blue (`#0F172A`) background, bright cyan (`#06B6D4`) for digital UI elements/temperature readouts, and clean white (`#F8FAFC`) for text.
- **Typography:** Monospaced fonts for data (temperatures, times) paired with a clean, geometric sans-serif for headlines.
- **Hero:** A macro shot of a vacuum-sealed bag with perfect clarity, overlaid with floating, semi-transparent UI elements showing temperature curves and timer counts.
- **Sections:** 'The Science' (diagrams of water displacement), 'The Gear' (product shots with technical annotations), 'The Results' (side-by-side texture comparisons).
- **Motion:** Subtle breathing animations on the UI overlays; smooth, linear transitions between sections (no bounce).
