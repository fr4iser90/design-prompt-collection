# Cactus Core Eco

Design a landing page for 'Cactus Core', an eco-brand using cactus materials. Palette: Clay (#D3C5B5), Cactus-Green (#5C7F56), Dark Grey (#333333). Typography: Organic, slightly rounded sans-serif (e.g., Quicksand) to reflect plant forms. Layout: Organic, non-grid shapes. Hero: Macro shot of cactus skin with water droplets. Sections: 'Sustainable Source', 'Product Lifecycle', 'Shop'. Use organic blob shapes for image containers. No rigid grids. Focus on texture and life.
