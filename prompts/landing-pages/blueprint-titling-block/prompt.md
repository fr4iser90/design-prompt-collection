# Blueprint Titling Block

Design a landing page for 'Draft & Scale', a structural engineering consultancy. The entire page is structured like a large-format architectural blueprint, specifically focusing on the 'Titling Block' (the standardized information box in the corner of drawings) as the primary UI component.

**Visual Rules:**
- **Background:** 'Blueprint Blue' (#003366) with a subtle white grid overlay (10px spacing).
- **Typography:** 'Architects Daughter' or similar hand-drawn font for labels (to simulate drafting pen), and a clean sans-serif (e.g., 'Helvetica Now' or 'Inter' if allowed, but prefer 'Roboto Condensed') for legibility. All text is white.
- **The Gag:** Content is not in 'sections' but in 'fields' of a titling block. Each field has a label (e.g., "PROJECT", "SCALE", "DATE") and a value. The layout is a rigid grid of these fields.
- **Accents:** Thin white lines separating fields. A 'Revision' stamp (e.g., "REV 03") in the corner.

**Deliverable:** HTML/CSS implementation of a grid-based layout that mimics a technical drawing sheet.
