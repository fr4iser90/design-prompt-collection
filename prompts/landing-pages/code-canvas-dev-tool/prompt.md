# Code Canvas Dev Tool

Design a landing page for 'Code Canvas', a developer productivity tool. The hero is a stylized code editor. The background is Dracula theme (#282a36). Syntax highlighting colors are #8be9fd (cyan) and #ff79c6 (pink). The text is monospaced. Key feature: 'Comments come to life'. As the user scrolls, code comments (green text) transform into floating UI widgets. Layout is split: Code on left, Generated UI on right. Motion: Typewriter effect for code, fade-in for widgets.
