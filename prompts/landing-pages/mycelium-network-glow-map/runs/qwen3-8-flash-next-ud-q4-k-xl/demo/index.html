The protocol

Three phases of symbiotic computation.

RhizoNet doesn't deploy. It colonizes. Each phase mirrors the life-cycle of the organisms that power it.

❋
PHASE 01

Inoculation

Seed a substrate node with a starter culture. Within hours it establishes root contact with the wider mesh and negotiates its first routing weights.

⌁
PHASE 02

Mycorrhization

Hyphae branch and fuse, forming redundant chemical pathways. Data is encoded in electrochemical gradients — no electricity, no heat, no clock.

✦
PHASE 03

Fruiting

Computation surfaces as emergent output. The network self-heals damaged paths and reallocates load the moment a node goes dormant.
