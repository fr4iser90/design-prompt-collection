# Mycelium Network Glow Map

Create a landing page for 'RhizoNet', a decentralized bio-computing network.

**Visual Core:**
- **Background:** Very dark forest green/black (#052e16). Texture: Subtle noise resembling damp soil or petri dish agar.
- **Hero Element:** A live WebGL or Canvas visualization of a mycelial network. Thin, branching white/green lines connect glowing nodes.
- **Interaction:** Mouse movement 'stimulates' the network, causing nearby nodes to pulse brighter and send 'data packets' (small light particles) along the branches.
- **Content:** Overlay technical specs on the right. Use a 'terminal' aesthetic but with organic, curved fonts for headers.

**Constraints:**
- Lines must not look like standard 'SaaS connection lines'. They must be irregular, branching, and fractal-like.
- Glow effects should be subtle, not neon. Use `mix-blend-mode: screen` for light.
- Text must remain readable against the moving background (use backdrop-filter blur on content containers).

**Deliverable:**
- Interactive HTML/CSS/JS (Canvas/WebGL) with responsive text overlays.
