# Vault Archive Stamp

Create a landing page for 'Vault,' a digital document preservation service. The aesthetic is 'bureaucratic retro-modern': think old library cards, rubber stamps, and manila folders, but executed with crisp, modern web precision.

**Visual Rules:**
- Background: Off-white paper texture (#f4f1ea) with subtle noise.
- Text: Dark charcoal (#2c2c2c), serif font for headings (e.g., 'Courier Prime' or 'Special Elite' for a typewriter feel, paired with a clean serif like 'Merriweather' for body).
- Accents: 'Verified' Red (#d32f2f) used exclusively for stamp graphics and key CTAs.
- Components: Elements should have slight 'ink bleed' or rough edges on borders. Use CSS filters for a slight paper curl effect on cards.

**Motion & Interaction:**
- **Stamp Action:** When a user scrolls to a 'Verified' section, a red circular stamp animates onto the screen with a slight rotation and 'thud' scale effect.
- **Hover:** Links underline with a jagged, hand-drawn stroke style.
- **Scroll:** Sections reveal as if being pulled out of a drawer (slide-up with slight perspective tilt).

**Deliverable:** Hero section with a large 'Archived' stamp, plus a 'Recent Collections' grid.
