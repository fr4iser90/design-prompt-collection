# Cold Chain Logistics

Design a landing page for 'FrostLine', a cold-chain logistics provider.

**Visuals:**
- **Background:** Deep navy `#0f172a` with subtle, animated frost crystal patterns that appear and recede.
- **Typography:** Use a heavy, industrial stencil font for headings (e.g., 'Stencil' or 'Black Ops One') and a clean, monospaced font for data labels (e.g., 'Roboto Mono' or 'Space Mono').
- **Elements:** Incorporate 'Warning: Perishable' and 'Maintain Temperature' labels as decorative UI elements. Use high-contrast red `#ef4444` for critical alerts and green `#10b981` for 'In Range' status indicators.
- **Layout:** A strict grid system with thick, white border lines dividing sections, mimicking shipping container structures.

**Motion:**
- Frost crystals slowly grow from the edges of the viewport on scroll.
- Temperature readouts flicker slightly like old LED displays before settling on a value.

**Deliverable:** HTML/CSS/JS.
