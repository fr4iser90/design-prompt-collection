# Radio Scan Archive

Design a landing page for 'ScanArchive', a radio signal database.

**Visuals:**
- **Background:** Deep black `#050505` with a subtle CRT scanline overlay.
- **Typography:** Monospace font (e.g., 'VT323', 'Share Tech Mono') for all text to mimic old terminal/radio displays.
- **Elements:** Tuning dial graphics, frequency scales, and 'Signal Found' / 'Static' status badges. Use bright green `#00ff41` for active signals and red `#ff3333` for errors/static.
- **Layout:** A central 'console' layout with data fields and status indicators arranged like a vintage radio control panel.

**Motion:**
- Scanlines move slowly vertically.
- Text types out character-by-character like a terminal.
- 'Tuning' animation: A horizontal bar moves across the screen, 'finding' sections as the user scrolls.

**Deliverable:** HTML/CSS/JS.
