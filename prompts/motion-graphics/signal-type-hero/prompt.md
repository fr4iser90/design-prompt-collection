# Signal Type Hero

Build a **full-bleed kinetic typography hero** for fictional studio **Signal Atelier**. One motion prototype — not a portfolio site, not a lower-third.

**Energy:** editorial Communication Design — bold, precise. Invent the look; do not clone real agencies.

**Palette:** ink `#0E0E0C`, paper `#F4F0E6`, signal red `#E23B2F`, mute `#8A857A`.
**Type:** display **Fraunces**, body **IBM Plex Sans**. Never Inter/Roboto/Arial.

## Scene sheet (autoplay ~6s)
1. **0.0–0.8s** — Tiny cropped glyph cluster of **COMMUNICATION** through a hard mask.
2. **0.8–2.0s** — Masks open; glyphs on different axes assemble; one word overscales then snaps.
3. **~1.5s POSTER** — **Communication Design** dominant; **Signal Atelier** secondary.
4. **2.0–4.5s** — Soft parallax on letter layers; stays legible.
5. **4.5–6.0s** — Hold; Space/click replays.

## Hard rules
- Brand hero-scale by poster frame. Shots capture ~1.5s.
- Ban: nav, CTAs, project cards, purple glow.

## Deliverable
Single HTML (CSS/SVG + rAF). Reduced-motion → static poster.
