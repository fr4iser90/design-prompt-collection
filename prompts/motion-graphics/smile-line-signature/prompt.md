# Smile Line Signature

Build a **signature path animation** for **Warmmark Studio**: brands that make people smile — without emoji or mascots.

**Palette:** warm paper `#F7F1E8`, ink `#1A1512`, coral `#E36A5D`, olive `#5C6B4A`.
**Type:** display **Cormorant Garamond**, body **IBM Plex Sans**. Never Inter/Roboto/Arial.

## Scene sheet (~7s loop)
1. **0.0–1.2s** — Single precise line draws across a quiet field.
2. **1.2–2.8s** — Line takes geometric turns → abstract signature mark (not yet a smile).
3. **~1.5s POSTER** — Line mid-draw + early mark; soft **Warmmark** optional.
4. **2.8–4.5s** — Morph into a reduced smile-curve (graphic, not emoji).
5. **4.5–6.2s** — **Warmmark Studio** lands; curve breathes once.
6. **6.2–7.0s** — Hold / loop. Space replays.

## Hard rules
No emoji, mascot, nav/CTA. Poster @ 1.5s must look intentional.

## Deliverable
Single HTML (SVG path + rAF). Reduced-motion → final smile + wordmark still.
