# Smile Line Signature — Extended

## Concept
Identity motion: one line becomes a reusable smile-curve signature for Warmmark Studio. Graphic and abstract — never a cartoon face.

## Scene sheet
| Time | Action |
|------|--------|
| 0.0–1.2s | Line draw |
| 1.2–2.8s | Geometric signature mark |
| ~1.5s | Poster — mid-path |
| 2.8–4.5s | Morph to smile-curve |
| 4.5–6.2s | Warmmark Studio + breath |
| 6.2–7.0s | Hold / loop |

## Poster frame
At ~1.5s: active stroke on warm paper with intentional structure; optional soft Warmmark; coral sparingly. Must not look empty in 1200×630.

## Palette
- `#F7F1E8` · `#1A1512` · `#E36A5D` · `#5C6B4A`

## Type
- Cormorant Garamond · IBM Plex Sans · never Inter/Roboto/Arial

## Frame
- Full-bleed or centered stage; generous space; mobile scales stroke

## Motion
1. Path draw + morph
2. Micro breath on curve
3. Space replay

## Constraints
- [ ] No emoji / mascot
- [ ] Poster @ 1.5s intentional
- [ ] Wordmark by end
- [ ] Reduced-motion → final still
- [ ] Single HTML

## Acceptance criteria
- [ ] Autoplay loop ~7s
- [ ] Smile is graphic mark, not emoji
- [ ] Warmmark Studio legible on hold
- [ ] No landing chrome
