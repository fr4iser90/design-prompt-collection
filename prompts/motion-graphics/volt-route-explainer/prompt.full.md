# Volt Route Explainer — Extended

## Concept
Infrastructure storytelling with utility calm: chalk diagrams on asphalt, one teal reroute, one hazard accent. Four beats teach problem → path → payoff → hold.

## Beat sheet
| Time | Beat | On screen |
|------|------|-----------|
| 0.0–2.2s | Problem | **CONGESTED GRID** + bottleneck pulse |
| 2.2–4.8s | Mechanism | Teal path draw **REROUTE** |
| 4.8–7.4s | Payoff | Count-up **+18% headroom** + **Volt Route** |
| 7.4–9.2s | Hold | Brand + diagram quiet |
| 9.2–10.0s | Black | Loop |

## Poster frame
At ~1.5s: **CONGESTED GRID** title + bottleneck nodes pulsing on asphalt — diagram readable in still.

## Palette
- `#121417` asphalt
- `#E6E2D6` chalk
- `#F0B429` hazard
- `#5EC4B4` signal / route

## Type
- Space Grotesk — titles / brand
- IBM Plex Mono — labels / count-up
- Never Inter / Roboto / Arial

## Frame
- 16:9 centered stage
- Diagram left or full-bleed; type hierarchy clear at freeze

## Motion
1. Entrance: title slam + node pulse
2. Ambient: soft grid shimmer during hold
3. Interaction: Space replay; story does not need pointer

## Constraints
- [ ] Four named beats with clock times
- [ ] Brand hero on payoff
- [ ] No SaaS landing chrome
- [ ] Reduced-motion → final payoff still

## Acceptance criteria
- [ ] ~10s autoplay loop
- [ ] Payoff freeze shows brand + metric
- [ ] Route draw is readable as a diagram
- [ ] Distinct from interactive animation studies
