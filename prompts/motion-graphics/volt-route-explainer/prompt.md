# Volt Route Explainer

Build a **10-second looping explainer** for **Volt Route** (fictional grid-routing tool). Four story beats. Not a landing page. Not a dashboard.

**Frame:** 16:9. Autoplay loop; Space restarts. Reduced-motion: jump to final payoff card.

**Palette:** asphalt `#121417`, chalk `#E6E2D6`, hazard `#F0B429`, cool signal `#5EC4B4`.
**Type:** display **Space Grotesk**, mono labels **IBM Plex Mono**. Never Inter/Roboto/Arial.

## Beat sheet
1. **0.0–2.2s — Problem** — Title card **CONGESTED GRID**. Stylized city nodes pulse; one bottleneck flashes.
2. **2.2–4.8s — Mechanism** — Line draws an alternate route (teal `#5EC4B4`) around the bottleneck; label **REROUTE**.
3. **4.8–7.4s — Payoff** — Capacity bar grows; count-up **+18% headroom**; brand **Volt Route** lands hero-scale.
4. **7.4–9.2s — Hold** — Clean diagram + brand; hazard stripe accent only as thin rule.
5. **9.2–10.0s** — Hard cut to black; loop.

## Hard rules
- Exactly one idea per beat; no feature-card dump.
- Mid-payoff still (t≈6.5s) must read as a poster.
- Ban: pricing, signup CTAs, purple glow, cream+terracotta.

## Deliverable
Single HTML (Canvas or SVG + rAF timeline).
