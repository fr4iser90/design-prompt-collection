# Meridian Audit Lockup — Extended

## Concept
A compliance brand that feels like a sealed ledger, not a SaaS dashboard. The sequence is pure identity: monogram → wordmark → subline, timed like an opening title. Gold is sparingly used as registration marks and light, never as neon.

## Beat sheet
| Time | Action |
|------|--------|
| 0.0–1.2s | Gold rule draw; **M** monogram stroke-draw on `#0B1210` |
| 1.2–3.4s | Path morph to **MERIDIAN**; metallic sweep `#C9A227` |
| 3.4–5.2s | **AUDIT** subline; ledger hairlines |
| 5.2–7.0s | Hold + dust |
| 7.0–8.0s | Fade to black; seamless loop |

## Poster frame
At ~1.5s: monogram mid-morph or early **MERIDIAN** stems visible on dark field with gold rule — brand readable in 1200×630 crop.

## Palette
- Background `#0B1210`
- Panel / depth `#15201C`
- Primary ink `#E8F0EA`
- Accent gold `#C9A227`
- Hairline mute `#3A4A42`

## Type
- Display: PP Neue Montreal / Söhne — wordmark
- Body: IBM Plex Sans — subline only
- Never Inter, Roboto, Arial, system-ui

## Frame
- Aspect **16:9**; stage max-width ~1200px centered
- Safe margins ≥6% from frame edges
- Letterboxing allowed outside the stage

## Motion
1. Entrance: stroke-draw + rule (1.2s, ease-out cubic)
2. Ambient: dust drift + hold breath (during 5.2–7.0s)
3. Interaction: Space/click = restart from 0; optional scrub — story plays without pointer

## Constraints
- [ ] Timed beat sheet honored (±0.3s OK)
- [ ] Brand hero-readable mid-hold
- [ ] No landing chrome / CTAs / cards
- [ ] Reduced-motion → final lockup still
- [ ] Single HTML deliverable

## Acceptance criteria
- [ ] Autoplay loop ~8s without user input
- [ ] Freeze at mid-hold shows **MERIDIAN** / **AUDIT** clearly
- [ ] No purple-glow or cream+terracotta defaults
- [ ] Contrast AA for ink on bg
