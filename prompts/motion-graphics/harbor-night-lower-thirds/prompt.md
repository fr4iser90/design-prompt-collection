# Harbor Night Lower Thirds

Build a **6-second looping broadcast lower-third** for the fictional show **Harbor Night**. One nameplate system: enter → hold → exit. Not a website. Not a UI panel demo.

**Frame:** 16:9. Title-safe ≈10% margins. Autoplay; Space restarts. Reduced-motion: static final nameplate.

**Palette:** deep harbor `#071018`, fog `#1A2A36`, foam `#D7E6EF`, signal amber `#E0A45A`.
**Type:** display **Fraunces**, UI/name **IBM Plex Sans**. No Inter/Roboto/Arial.

## Beat sheet
1. **0.0–0.7s** — Amber bar wipes in from left along lower third; fog plate slides up 24px.
2. **0.7–1.6s** — Primary line **MAYA CHEN** snaps in (tracking settle); secondary **Harbor Pilot · Night Desk** fades.
3. **1.6–4.2s** — Hold. Subtle live-dot pulse on amber pip; plate stays rock-solid.
4. **4.2–5.2s** — Exit: type collapses left; plate slides down; bar retracts.
5. **5.2–6.0s** — Empty frame beat; loop.

## Hard rules
- **Harbor Night** show bug (small) top-right OR integrated into plate — still readable.
- Still at hold (t≈2.5s) must read as a broadcast still.
- Ban: landing heroes, CTAs, card grids, purple glow.

## Deliverable
Single HTML (CSS/SVG + rAF). Tags may mention Remotion; runtime must be plain HTML.
