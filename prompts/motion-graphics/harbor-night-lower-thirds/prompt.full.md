# Harbor Night Lower Thirds — Extended

## Concept
Night-desk maritime news energy: fog, foam type, one amber signal. The lower-third is the product — enter, identify, leave clean. Think broadcast package, not web chrome.

## Beat sheet
| Time | Action |
|------|--------|
| 0.0–0.7s | Amber wipe + plate rise |
| 0.7–1.6s | **MAYA CHEN** + role line |
| 1.6–4.2s | Hold + pip pulse |
| 4.2–5.2s | Collapse exit |
| 5.2–6.0s | Empty; loop |

## Poster frame
At ~1.5s: lower-third plate with **MAYA CHEN** + role line and amber pip — broadcast still, title-safe margins.

- 16:9 stage; title-safe ≥10%
- Lower-third occupies bottom ~22% of frame height

## Motion
1. Entrance: wipe + rise (0.7s, ease-out)
2. Ambient: amber pip pulse during hold
3. Interaction: Space = replay only
