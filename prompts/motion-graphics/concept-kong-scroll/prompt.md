# Concept Kong Scroll

Build a **scroll-progress storytelling prototype** for **Northmark Studio** under **Concept is King. Design is Kong.** Not a full website.

**Idea:** One point becomes a visual system across six continuous phases. Each phase grows from prior elements — never six fade-in cards.

**Palette:** `#111114`, chalk `#EDE6D6`, kong `#C45C26`, cool `#4A6FA5`.
**Type:** display **Satoshi** or **General Sans**, mono **IBM Plex Mono**. Never Inter/Roboto/Arial.

## Scene sheet
Scroll 0→1; **also autoplay** scrub 0→~0.35 in first 2s for shots.

1. Briefing — point in grid  
2. Idee — split forms  
3. Konzept — composed structure  
4. Design — type + lines  
5. System — multiplied abstract applications (no fake client logos)  
6. Ergebnis — densify + **Northmark Studio**

## Poster frame (~1.5s)
Around Konzept→Design: composed forms + **Concept is King** readable.

## Hard rules
Continuous morph; ban card slideshows, nav, CTAs, purple glow.

## Deliverable
Single HTML (SVG/CSS + rAF). Reduced-motion → Ergebnis still.
